A game where you are stuck in a machine and you need to survice there for 60s, save yourself from machine's pistons and saw

## Controls
- Move: A / D or arrow keys for mobiles and touch screen
- Jump: Space / W / Up
- Restart: R        Menu: Esc or H      Mute: H
- Touch: on-screen buttons

## Pickups
- samosa: +1, +3 and +5 (rarer ones appear in reskier spots)
- WandaBand: apeears one per run and gives you one extra life when collected
- Shield: lasts 10secs and blocks the saw from the direction you are facing
